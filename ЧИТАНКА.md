# Force Quit Shortcut

**Швидке, легке та зручне закриття завислих програм для GNOME Shell.**

Розширення покликане заповнити прогалину в користувацькому досвіді, стати ідеальним доповненням до стандартного Системного монітора. Чи може конкурувати із системним монітором Ресурси? Цілком. Своєю швидкістю, простотою і мінімальним споживанням ресурсів системи.

## Можливості

- **Force Quit Shortcut**: Вікно примусового закриття програм у стилі macOS зі списком запущених процесів та інформацією про використання ЦП і пам'яті. Виберіть програму і примусово закрийте її, якщо вона зависла.
- **Багатомовна підтримка**: Інтерфейс, готовий до перекладу.

## Передісторія та філософія

Розширення було створене на основі діалогу "Force Quit" з чудового проєкту [Kiwi Menu](https://github.com/kem-a/kiwi-menu) від чудового **kem-a**. 

**Чому окреме розширення, а не доповнення до оригіналу?**
Kiwi Menu має чітку концепцію: допомогти користувачам macOS відчувати себе як вдома у середовищі GNOME. Автор проєкту прагне зберегти його мінімалістичним і не ускладнювати кодову базу. 

Я ж ніколи не користувався macOS, не відчуваю до неї ностальгії і не маю потреби переносити її досвід на Linux. Мені просто не вистачало зручного інструменту для екстреного закриття програм (особливо Windows-застосунків, що працюють через Wine/Proton, та іноді Linux-програм). Щоб не перевантажувати Kiwi Menu невластивим йому функціоналом, я вирізав виключно діалог примусового закриття і доопрацював його, перетворивши на самостійний інструмент. 

*P.S. Щиро вдячний kem-a не тільки за розширення і застосунки, а й за позицію. Paldies!*

## Особливості та покращення

Порівняно з оригінальним діалогом, тут реалізовано низку архітектурних та користувацьких покращень:

* **Миттєвий виклик:** В оригіналі діалог щоразу запускався наново, що створювало затримку при виклику. Тепер після першого запуску процес залишається у фоні задля миттєвої появи вікна і потребує всього близько 20 МБ пам'яті.
* **Відкладений старт:** Додано опціональний параметр вибору часу затримки запуску фонового процесу. Одразу після входу в систему не виникає потреби в екстреному закритті програм, тому розширення не забирає ресурси під час старту середовища, а завантажується через вказану кількість секунд.
* **Керування з клавіатури:** Додано клавіатурні скорочення для максимально швидкої взаємодії без мишки.
  
## Клавіатурні скорочення

| Скорочення           | Дія                                                    |
| -------------------- | ------------------------------------------------------ |
|`Alt`+`Super`+`Escape`| Виклик вікна                                           |
| `q` / `Delete`       | Закрити процес                                         |
| `w` / `a` / `↑`      | Навігація списком вгору                                |
| `s` / `d` / `↓`      | Навігація списком вниз                                 |

## Встановлення
```bash
# Клонування сховища
git clone https://github.com/Dymkom/force-quit-shortcut.git
cd force-quit-shortcut

# Створюємо теку для розширення
mkdir -p ~/.local/share/gnome-shell/extensions/force-quit-shortcut@dymkom

# Копіюємо файли до нової теки
cp -r * ~/.local/share/gnome-shell/extensions/force-quit-shortcut@dymkom/

# Компілюємо схеми
glib-compile-schemas ~/.local/share/gnome-shell/extensions/force-quit-shortcut@dymkom/schemas

# Вмикаємо розширення
gnome-extensions enable force-quit-shortcut@dymkom
```
Примітка: що б розширення запрацювало, необхідно здійснити вихід із системи.

## Рекомендую

1. [Kiwi Menu](https://extensions.gnome.org/extension/8697/kiwi-menu/) та [Kiwi (is not Apple)](https://extensions.gnome.org/extension/8276/kiwi-is-not-apple/) від [kem-a](https://github.com/kem-a). Іноді хочеться трохи іншого користувацького досвіду, і ці два розширення його забезпечать. Мені до вподоби, час від часу користуюсь.
2. Також від [kem-a](https://github.com/kem-a), на мою думку, незамінний інструмент [Розпорядник AppImage](https://github.com/kem-a/AppManager). Найкращий у своєму роді, його стилістика запозичена з процесу встановлення .dmg на macOS. Користуюсь весь час.
3. Розширення [gradia-capture](https://github.com/AlexanderVanhee/gradia-capture) від [Vanhee](https://github.com/AlexanderVanhee). Доповнює різноманітними інструментами класичний процес створення знятків. Варто мати!
4. Розширення [Restart To](https://github.com/tiagoporsch/restartto), зручний перехід до іншої системи, біос. Для мене є перевагою відсутність при запуску списку Grub (або аналогів), або затикування кнопки входу в біос. Раніше доводилось налаштовувати кнопку при старті системи, аби встигнути відкрити список зі системами або дистрибутивами.
